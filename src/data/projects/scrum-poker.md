## Problem

Planning meetings can slow down when estimation tools are clunky, unclear, or overloaded. The goal was to create a focused experience where facilitators can quickly start a session and participants can vote without friction.

## My Role

I designed and built the application experience, front-end architecture, interaction states, and deployment path.

## Technical Decisions

- Used Vue and TypeScript for maintainable component-driven UI.
- Used Bun to keep the development/runtime workflow lightweight.
- Prioritized responsive layout and clear facilitator/participant flows.

## Impact

This project demonstrates front-end architecture, full-stack product context, deployment ownership, and the ability to turn a common team workflow into a polished web app.

## What I Would Improve Next

- Add analytics around session completion and user flow drop-off.
- Improve onboarding for first-time facilitators.
- Add deeper accessibility testing for keyboard and screen-reader workflows.
